# User Document Storage Service

A robust, extensible REST API for managing user documents in cloud storage. Built with Spring Boot 4 and Java 21, this service provides optimized search, download, and upload capabilities using Amazon S3.

## Prerequisites

- Java 21
- Docker & Docker Compose
- Gradle (or simply use the included Wrapper)

## Run the Application

Use the Gradle wrapper to start the Spring Boot application:

```sh
./gradlew bootRun
```
